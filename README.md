# Amar Ghor 🏠

A memory-powered miniature room decorator. Start with a quiet isometric room and unlock objects that represent your story.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## MVP
- Five independent decoration layers (laptop, books, plant, guitar, fairy lights)
- Day/night lighting
- Persistent selections in localStorage
- Reset and PNG export
- Responsive UI, no authentication

## Art direction
Warm miniature isometric diorama, inspired by the reference image. **Current scene is hand-authored SVG concept art**, not photorealistic 3D renders. Future production art should be exported from a single fixed-camera scene into full-canvas transparent WebP layers with consistent shadows and occlusion.

## Assets
No third-party models or copyrighted image crops included. See `public/assets/room/README.md` for layer specifications.
