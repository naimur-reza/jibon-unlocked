# Jibon Unlocked 📒

Bangladesh-first retro life scrapbook generator built with Next.js, TypeScript, Tailwind and `html-to-image`.

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## MVP

- 25 Bangla experience options across five category steps
- LocalStorage persistence, no login and no backend
- Dynamic scrapbook poster with six highlighted selections
- Download a 1080 × 1350 PNG; native file share where supported
- No user-uploaded photos or personal experience data sent to a server

## Verification

Run `npm run typecheck` and `npm run build`. These were not verified in the initial authoring environment because package installation timed out. Test PNG export and Bengali font shaping on real Android Chrome and iOS Safari before launch.
